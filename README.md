# PolyQuant Intelligence

Polymarket-focused prediction-market quantitative research, forecasting, backtesting, paper-trading and risk-control platform.

> Default mode is **Paper/Demo**. Live execution is disabled unless explicitly configured.

## V1 scope

- Polymarket market discovery and live/public market-data adapter
- Quant feature engine and opportunity ranking
- Probability estimation interface with calibrated demo ensemble
- Probability-edge, cross-market and order-book timing strategies
- Backtest engine with explicit slippage/fee assumptions
- Paper trading portfolio and order simulation
- Hard risk controls and fractional-Kelly sizing
- FastAPI backend and Next.js dashboard
- Docker Compose development stack

Full setup instructions are added as the implementation lands.
